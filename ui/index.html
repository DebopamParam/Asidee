Workspaces

A workspace is a folder on this Mac where an agent works as you, with no wall around it. It is not a sandbox: use one only for what needs this Mac, such as its GPU.

New workspace

Templates

A template is a saved sandbox that new ones start from, without the usual login files. Save one from a sandbox's ⋯ menu. Removing a template keeps the sandboxes made from it working.

Make a coding-tools template

Makes a sandbox from the built-in image, installs tmux, fd, zip, htop, vim and nano from its packages and Claude Code and Codex from npm, runs your script if you choose one, checks each tool, saves the template and removes the sandbox. All of it runs inside that sandbox. It takes a minute or two.

The versions start as this Mac's; blank means the latest.

Extensions

    
Extensions are optional add-ons. Each adds buttons to a sandbox, such as copying in your logins or setting up T3 Code. None come installed. An extension's action runs one of its commands on this Mac, with asd first on its PATH.
