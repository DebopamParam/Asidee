Usage now

Measured every few seconds while this page is open. CPU is the share of one CPU, so 200% is two CPUs busy. Disk is the last measurement of the disk watch, a start or a verify.

Templates

A template is a sandbox's files, saved without the usual login files. Save one from a sandbox's More menu. Removing a template keeps the sandboxes made from it working.

Prepare an agent template

Makes a sandbox from the built-in image, installs tmux, fd, zip, htop, vim and nano from its packages and Claude Code and Codex from npm, runs your script if you choose one, checks each tool, saves the template and removes the sandbox. All of it runs inside that sandbox. It takes a minute or two.

The versions start as this machine's, as the CLI chooses them; blank means latest.
